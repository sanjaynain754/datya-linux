# Datya Linux Project Scope

Datya Linux is intended to be a **general-purpose, open, and customizable operating system**. It is not restricted to ethical hackers or cybersecurity professionals. People may use it for everyday computing, education, software development, administration, research, privacy-focused work, security operations, or other lawful purposes that they choose.

The project provides software, defaults, documentation, and security signals. It does not control how a user configures or uses the system, and it cannot determine every consequence of activity performed in every Linux environment. Maintainers therefore make no guarantee that a particular use will benefit or harm a person, organization, device, or network.

This broad scope does not change the engineering posture. Datya should still avoid hidden telemetry, preserve user control, disclose capabilities, make network and privilege activity visible, and document limitations. Safety controls such as scope checks, dry-run defaults, signed packages, resource limits, and evidence logging are transparent product defaults—not claims that the system can control user behavior or prevent every misuse.

Users remain responsible for the systems they administer, the permissions they hold, applicable law, contracts, and the effects of their actions. Contributors should describe technical behavior accurately and should not claim that Datya provides absolute anonymity, untraceability, safety, or outcome guarantees.
